# Авито.Кухня

MVP сервиса доставки еды: платформа, через которую заведения принимают заказы, а пользователи
находят блюда и оформляют доставку.

> 🚧 Проект в разработке. Разделы ниже наполняются по мере готовности.

## Стек

- **Go** — платформа (`cmd/api`) и демонстрационный сервис заведения (`cmd/restaurant`)
- **PostgreSQL** — основное хранилище
- **Docker Compose** — запуск всего окружения
- **golangci-lint** — статический анализ, конфигурация в [`.golangci.yml`](.golangci.yml)

## Структура репозитория

```
cmd/api/           точка входа платформы
cmd/restaurant/    точка входа сервиса заведения
```

## Разработка

```bash
make help    # список доступных команд
make build   # собрать оба сервиса
make lint    # статический анализ
make test    # тесты
```
